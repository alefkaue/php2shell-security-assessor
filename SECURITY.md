# Security and privacy

This is an offline educational project. Do not upload production inventories, raw evidence,
credentials or private reports to public issues. Report a reproducible software issue privately
through GitHub's private vulnerability reporting when enabled; otherwise omit sensitive data.
No production-security guarantee is made. Review inputs and output before sharing.

Runtime dependencies: Python standard library only. Build isolation may download setuptools;
keep the build toolchain updated. GitHub Actions are pinned to reviewed commit IDs.
